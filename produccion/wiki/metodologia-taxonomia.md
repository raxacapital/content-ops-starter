# Decisión de taxonomía: Hurtado vs Sampieri

## Regla de decisión

**Nunca las dos.** Se elige una sola en F0 y rige todo el proyecto.

| Condición | Taxonomía |
|---|---|
| El producto comprometido es una propuesta, plan, programa, modelo o manual | **Hurtado** (holopráxica) |
| Cualquier otro caso | **Sampieri** (estándar) |

## Hurtado — Investigación holística

- Produce ficha holopráxica
- Estadios progresivos: exploratoria → descriptiva → comparativa → analítica → explicativa → predictiva → proyectiva → interactiva → confirmatoria → evaluativa
- El verbo del objetivo debe coincidir con el estadio

## Sampieri — Investigación estándar

- Produce cadena de producción
- Alcances: exploratorio, descriptivo, correlacional, explicativo
- El verbo del objetivo debe coincidir con el alcance

## Errores frecuentes

- Mezclar las dos taxonomías en un mismo documento
- Usar un verbo de alcance explicativo con datos correlacionales
- Elegir Hurtado solo porque "suena más completo"
