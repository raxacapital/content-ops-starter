# Modos de operación

## PRODUCCIÓN

El sistema redacta el documento. La dueña supervisa y aprueba.

- Las skills de composición (02t, 03t, 04t / 02f, 03f, 04f) producen texto
- `teprih-estilistica` edita directamente
- Los validadores corren automáticamente

## ACOMPAÑAMIENTO

El sistema guía; el autor escribe.

- Las skills explican qué debe contener cada sección
- Revisan lo que el autor escribió
- `teprih-estilistica` marca y explica; el autor corrige
- La transcripción OCR sí la hace el sistema (producir insumo no es redactar)

## Cuándo se elige

Se fija en F0 según quién es el autor del documento. No cambia durante el proyecto.
